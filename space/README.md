# PulseCore Space Engine (v1.0.0 Architecture Specification)
**Платформа:** VietSites & SYNAPTIQ Lab • PulseCore™ Technology  
**Назначение:** Централизованный движок бронирования рабочих мест, переговорных комнат, залов для мероприятий и управления резидентами для коворкингов, коливингов и многофункциональных пространств (Мастер-шаблон №3: PRIME Space).

## Архитектура
- `space-engine.css` — стили интерактивной шахматки бронирования, карточек тарифов (Hot Desk, Dedicated Desk, Private Office, Meeting Room) и панели резидентов.
- `space-engine.js` — ядро бронирования с поминутной тарификацией, предотвращением коллизий переговорных комнат и сквозной Cloudflare D1 синхронизацией.
